# ChaoticDImensions PAP

Área dedicada aos documentos da PAP do projeto **Chaotic Dimensions**.

## Estrutura

- `Documents/`: relatório principal, modelo, normas e relatórios base.
- `Backups/`: versões anteriores e cópias de segurança do relatório.
- `Generated/`: media extraída, documentos gerados, conversões temporárias e saídas auxiliares.
- `Tools/`: scripts usados para gerar, atualizar, validar ou compactar anexos do relatório.

Esta pasta fica separada do mod e dos assets para evitar misturar documentação escolar com arquivos usados diretamente pelo tModLoader.
