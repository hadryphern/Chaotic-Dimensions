# ChaoticDimensions Mod

Esta é a pasta real do mod usado pelo **Terraria / tModLoader**.

Ela mantém a estrutura esperada por `ModSources`:

- `ChaoticDimensions.csproj`
- `build.txt`
- `Common/`
- `Content/`
- `Localization/`
- `Sounds/`
- `Assets/`

## Build

```sh
dotnet build ChaoticDimensions.csproj
```

Ou, a partir da raiz do repositório:

```sh
dotnet build "ChaoticDimensions Mod/ChaoticDimensions.csproj"
```

Arquivos de teste, sprites antigas, documentação e ferramentas ficam fora daqui, em `../ChaoticDimensions Assets/`.
